# Player exit artwork

Generated with the built-in image tool, using the Garden / Image 2 Host-Native workflow. Native text supplies the localized Exit label. Original output is preserved in Codex generated images; the app uses a 600px alpha-preserving copy, cropped for display only.

Asset: `Clipo/Resources/Assets.xcassets/Player/CourtExitControl.imageset/court-exit.png`

## Prompt

Create an original production-ready raster UI asset for Clipo, a premium tennis video app. One single compact horizontal pill button, front-facing orthographic, width to height ratio 2.6:1, centered on a truly transparent canvas with minimal transparent margin. Dark forest green matte enamel face (#102d25), restrained fine warm ivory rim, subtle tactile tennis-racket-grip texture, elegant understated bevel, crisp edges, no chunky plastic/gloss. On the far right inside the pill draw a small original ivory exit/doorway arrow symbol pointing right. Leave the left two-thirds clean blank space for native localized 'Exit' text to be added by the app. No text, no letters, no logo, no tennis balls, no extra objects, no surrounding card, no mockup, no screenshot. Designed to remain clear at 84 by 32 points over video. The asset itself must be the whole button and icon, with an alpha-transparent exterior. High craft, quiet sporty editorial feel.
