## 一、接口文档已经写明的广告规则

| 项目 | 文档要求 |
| --- | --- |
| 每日基础观看 | `dailyWatchLimit`，示例为 5 |
| 前三次完整激励广告 | 分别读取 `firstAdRewardWatchCount`、`secondAdRewardWatchCount`、`thirdAdRewardWatchCount`，示例均为 3 |
| 第四次完整激励广告 | 文本明确写明当日无限观看；不等于无限收藏 |
| 基础收藏／每次收藏奖励 | 示例均为 5，但字段命名和注释存在冲突，见下面第 1 项 |
| 额度耗尽 | 提示观看激励广告 |
| 广告无填充 | 幸运奖励弹窗和奖励动画；不推进完成广告轮次 |
| 第四轮无填充 | 发第三轮的次数奖励；必须真正完成第四次广告才解锁无限观看 |
| 重置 | 每日凌晨 5 点；文档没有指定时区 |

这些不是需要重新设计的规则。数字示例不应替代后台正式配置；当前发布配置未取得时使用本地默认值。

## 二、仅保留文档冲突和缺失项

以下问题需要后端解释契约或补齐未定义规则；文档已有的规则不重新征求设计意见。

| 编号 | 文档疑问 | 需要明确的内容 |
| --- | --- | --- |
| 1 | 收藏额度字段命名与注释不一致 | `unlimitedAfterAdCount` 的注释是每日基础收藏，`favoriteBaseLimit` 的注释是每次广告收藏奖励。是否严格按这两个注释映射？请给基础值与奖励值不同的响应例子。当前代码尚未按此映射，不能视为已对齐。 |
| 2 | 激励广告类型前后矛盾 | 示例写 `adType=2`，字段表写 `5`。你已指定暂用 2；后端需统一正式取值，无需你重新选一次。 |
| 3 | `NB01` 表述矛盾 | “隐藏会员入口”和“点击购买提示服务繁忙”同时出现。为 true 时究竟隐藏入口，还是保留入口但拦截购买？ |
| 4 | `adStatus` 缺少枚举 | 字符串／数字各值分别代表什么？是否单独决定免广告？会员有效性已按文档使用 `rightExpireTime`，这点无需再确认。 |
| 5 | 广告奖励计数的归属 | 因观看耗尽和收藏耗尽触发的广告，是否共用完成次数？幸运奖励是只补本次耗尽的额度，还是同时补观看和收藏？文档未明确这两点。 |
| 6 | 扣额度的定义缺失 | 观看在开始播放还是达到一定时长时扣次？同一视频重播是否重复扣？取消收藏再收藏是否重新扣次、取消是否返还？ |
| 7 | 重置时区缺失 | 每日凌晨 5 点明确，但按设备、北京时间还是服务端时区？跨时区后如何计算同一天？ |
| 8 | 开屏频率缺失 | 文档只规定开屏类型，没规定首次未登录、每次冷启动、后台回前台的展示条件与频率。当前实现为已登录非会员冷启动尝试一次，需确认这一缺失规则。 |
| 9 | 完整平台分享链接契约缺失 | `externalLinks` 的单条接口说明为短链／落地页标识，缺少热门平台完整 URL 的接入例子。完整链接是否直接传入，是否需预先转换？文档没有额外转换接口。 |
| 10 | `usdPrice` 单位不明 | `999/9999` 是美分还是方案值？页面价格已确定 USD 9.99／99.99，不重新询价；需要的是后端参数含义。 |
| 11 | 取消／失败上报字段缺失 | 请给 `buySuccess` 的 `canceled`、`error` 请求例子：没有交易号和收据时能否省略／传空，重复上报如何处理？ |
| 12 | 换机／重装恢复订单接口缺失 | 本地没有 `purchaseID` 时，如何按 Apple 原始交易号／收据取得原订单及所属账号？还需明确重复验单的幂等规则。 |
| 13 | 自动续订／退款后的权益更新缺失 | 后端是否处理 Apple 的续订、退款、撤销等变化？验单成功后多久能从 `member/user/get` 读到更新？文档没有给出时序与同步方式。 |
| 14 | 会员免广告范围不完整 | 文档提供到期时间，但没有完整权益表。当前会员无限观看／收藏并跳过广告；请明确会员是否全部免广告。无需借此增加下载等未要求的新功能。 |

## 三、已有实现差异与联调阻塞，不能当成已完成

- **额外 60 秒冷却**：文档没有这个幸运奖励限制，不再作为“是否保留”的产品选择询问。按你的最新要求，不应把它当正式规则；当前代码仍存在，需要在实现对齐时移除。本次仅整理清单，未改业务代码。

- **发布配置**：此前 `getV2` 对 `platform=IOS`、`name=com.clipo.video`、`version=1.0.0` 返回 `1002000001 / The distribution package does not exist`。需要后台登记，或提供已登记包名。当前无正式配置时使用本地默认值，不代表后台已联通。本次未重新发诊断请求。
- **推荐内容**：此前推荐／搜索为空；需要后端检查该包的 `search-check` 与 `lcList.us` 内容配置。不能凭空补推荐数据。
- **媒体资源**：前轮第一条视频资源不可用，未重新验收；短码 `2DhdI8` 的第二条本次演示可播放。失效资源需要后台核查；如有签名到期／特殊请求头要求，应补充到媒体契约。
- **不存在的接口不自行扩展**：文档没有服务端额度核销、收藏／历史同步接口，当前保持本机存储，不另起云同步需求。真实删除账号也没有接口，继续沿用你已经批准的本地模拟；以后启用真实删除时再补契约。
