## 推荐与播放流畅度（2026-10-20 更新）

- 使用临时游客身份读取当前工程包名 `com.cliporows.toolskeep` 的 `/app-api/flow/search-check`：业务码 `0`，`list` 为 0 条，`hasMore=false`。未保存或输出令牌，未请求视频流；甲方已确认包配置正确，尚未添加视频，当前无需继续追问或排查空列表。
- 推荐页增加刷新入口，继续按服务返回的 feedId/cursor 分页、按视频 ID 去重；取消中的请求不再显示为服务错误。
- 推荐页与链接播放器共用有界播放器池，只保留当前及相邻视频，离开屏幕释放，内存警告释放非当前资源。当前视频开始播放后才为下一条做静默 preroll；这是临时播放缓冲，不是离线下载，不扣观看／缓存额度。
- 当前视频使用 AVFoundation 的自动缓冲与支持的 HLS 自适应码率；移除强制立即播放。首帧按 AVPlayerLayer 的实际显示就绪状态隐藏封面，缓冲时不主动销毁当前画面。
- 拖动进度条时仅更新位置，松手发起跳转；控制器串行合并 seek，循环播放等待跳转完成，旧播放项回调按代次隔离。加载等待 20 秒未恢复显示重试提示；手动暂停不被广告／前后台恢复流程强行续播。
- 已进行源码、SDK API 声明及 diff 静态检查；未编译、运行测试或启动模拟器／真机。未测得首帧时间、卡顿率或弱网表现，不能宣称零卡顿。需要真实推荐视频后再验证 CDN／HLS 分片和多码率配置。

## 启动、预登录与开屏广告（本次修改）

- 启动直接通过游客接口创建或复用真实会话，随后获取发布包和广告配置并进入首页。没有欢迎页确认步骤，也没有模拟登录成功。
- 同一进程已有会话沿用；按 2026-10-21 最新确认，每次冷启动都用原安装 UUID 重新请求游客登录，不因 Keychain 有 Token 而跳过。鉴权请求收到 HTTP 401 时自动通过原游客身份更新登录并重试一次。失败显示错误，不生成假用户。
- `adType=1` 为开屏，`adType=5` 为激励，`advertiser=google`。
- 开屏 `displayInterval` 的单位是分钟。冷启动（含首次未手动登录）及真正从后台返回时检查距离上次实际展示的间隔；不因临时 inactive、关闭广告而重复触发。
- 甲方已确认 `0` 表示无间隔限制，符合条件的启动／后台返回都可展示。支持 JSON 数字和数字字符串；正式模式缺失／负数／非法间隔不展示，不擅自当成零。计时通过 SDK impression 回调记录，本地持久化，冷启动不清零；失败请求不算展示。
- 有效会员跳过广告。游客身份或会员状态无法确认时跳过。支付、账号操作或其他广告进行中不叠加开屏；等待配置／加载设有超时，过期回调不能在用户已进入其他流程后突然弹出。
- `appId` 与 `adUnitId` 示例只有 `ca-app-pub-` 前缀，是占位而非可用正式 ID。本次继续使用 Google 官方测试广告；测试模式没有包广告配置时用零间隔。正式模式需要完整 ID 和包配置，且后台 App ID 必须与本机配置匹配。
- `adOrder`、`showIntervalRows`、`maxHourlyImps` 已明确本版忽略，不再列为待确认。
- 保留原启动图和 loading；新页面使用原创网球素材，遵循 ui-design-reference、ui-taste、Claude Design、Garden/Image 2 和 Duo 的状态连续性要求。

## 已确认的其他业务规则

1. `NB01=true` 时不能购买，可以显示提示；`adStatus` 忽略，会员按 `rightExpireTime` 判断。
2. 收藏免费。在线缓存用于离线观看，成功下载一个视频扣一次，重复缓存不扣。
3. 观看与缓存的额度、广告完成次数各自独立；各自完成第 4 次激励广告，解锁当天对应的无限额度。
4. 无填充幸运奖励只补对应额度，不推进广告轮次；第四轮无填充仍给第三轮的次数奖励。
5. 视频成功开始播放扣次，当天同一视频再次打开或循环不再扣。
6. 每天 UTC+0 的 05:00 重置。
7. 按 2026-10-21 最新确认，首页输入原样作为 `query` 交给 `search-check`；不再截取自有链接的短码，也不另建第三方抓取服务。
8. 支付取消／失败传真实已有信息，缺失项传空，由后台判断。重复交易由苹果信息和后端接口判定。
9. 后端不处理新游客与历史交易的恢复关联；现有 Apple 恢复入口和可识别原订单的补单保留，无法关联时不冒充恢复成功。
10. 用户权益通过 `member/user/get` 更新；会员免广告，观看和缓存不限额。
11. 推荐页通过 `search-check` 获取，内容由后台配；之前单条资源问题暂忽略。
12. 包登记问题先不处理。按最新要求移除本机模拟删除和退出入口，本版不提供删除账号功能，不再追问删除接口。

上述业务规则已于本轮按确认范围修改源码：

- 收藏免费；观看和下载使用独立额度及广告轮次，各自完成第 4 次广告后对应额度当天无限。幸运奖励只增加对应额度，不推进轮次，已移除 60 秒冷却；仅额度耗尽后可请求对应奖励广告。
- 账本按 UTC+0 的 05:00 重置。同一视频当日在线播放去重；成功缓存 ID 跨日保留，重复下载不再扣缓存额度。会员期间已播放的视频也记为当天看过，避免会员到期后同日重扣。
- 播放器选项增加离线下载，资料库增加 Downloads。HLS 使用 AVAssetDownloadURLSession，普通视频使用 URLSession 下载；完成文件并校验可播放后计数，下载失败／取消不扣。离线播放使用本机文件，不再消耗在线播放额度。下载完成日志保留到额度和索引都写入成功，可重试，避免中断后重复扣次。
- 原安装升级保留 UUID；识别干净重装时清除旧游客会话和安装 UUID，再自动创建新游客。历史付款账本及其原始归属不会被删除或转绑。
- 支付 canceled/error 按原订单所有者、真实已有收据和交易号上报 buySuccess；缺失字段为空。上报前持久化，网络失败时留待刷新／重启补报，不显示伪成功。
- 本轮复用现有原创图片按钮和图标，新增下载／额度文案覆盖七种语言。包名、账号删除、恢复购买契约、正式广告、Apple 登记、最终 Icon、协议及其他视觉收尾暂未处理。

本轮仅源码、配置、资源引用与差异检查。独立额度检查源码已更新但未执行；未编译、未启动应用、未下载视频、未请求广告或付款。
